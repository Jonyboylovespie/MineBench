# Changelog

## 1.0.0 — initial release

- Added Fabric 26.2 / Java 25 project scaffold with reproducible Gradle wrapper.
- Added explicit benchmark state machine with transition reasons and monotonic timestamps.
- Added fixed primitive frame sampling buffer and optional GPU timer ring abstraction.
- Added frame statistics, low-FPS definitions, stutter counts, bootstrap intervals, run aggregation, and comparison warnings.
- Added deterministic camera path interpolation and route hashing.
- Added a dedicated seeded Suite 1 world with fixed Overworld, Nether, and End coordinates.
- Added static panorama, three deterministic flythroughs, and real client geometry-invalidation workloads.
- Added chunk and renderer readiness gates before every scene.
- Added scene-contract hashing, route hashing, OpenGL metadata, and Iris shaderpack identification/hashing.
- Added environment fingerprints, validity evidence, and atomic report files.
- Added quick, standard, extended, managed status, keybind, command, and minimal results-screen client workflow.
- Added schemas, methodology/privacy documentation, tests, CI, and managed orchestration example.
- Added in-game world creation/opening and managed automatic world creation.
